# NOVA SPARK

A short, juicy survival game. You are a newborn star. Void wisps try to snuff you out. Sweep up stardust, pick upgrades, and stay bright.

## Play

Open `index.html` in a browser. Chrome / Edge / Firefox / Safari all work. No install.

- **Move:** WASD or arrow keys
- **Or hold mouse / finger** to drift toward the cursor
- **P** pause · **M** mute
- After a run, tap how it felt. That rating is the whole point of the play report.

## Play report

Menu → **Play report** → Copy → paste it back to Grok.

The report includes run lengths, upgrades you keep picking, what ends runs, control style, and your ratings so the next version can lean into what you actually enjoy.
